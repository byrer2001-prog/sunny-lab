# ☀️ 心晴实验室（Sunny Lab）

一个面向大学生的心理健康自助平台。用数据可视化呈现大学生心理现状，提供压力自测、呼吸放松训练、冥想音频、解压小游戏与心情日记等功能。

> AIDM7450 课程项目 · 重构优化版

## ✨ 功能特性

| 模块 | 说明 |
| --- | --- |
| 📊 数据可视化 | 三张真实数据图表（年龄组抑郁风险柱状图、焦虑风险环形图、情绪调节百分比堆叠条），核心指标数字滚动，图表滚动到视口才绘制、动画随下滑开始 |
| 🧭 压力检测 | PSS-10 知觉压力量表（10 题，含 4 道反向计分题），键盘快捷键（1–5 作答 / Enter 下一题），结果按 0–13 / 14–26 / 27–40 三档给建议，附历史趋势折线图 |
| 🌬 呼吸训练 | 3 种呼吸节奏（经典放松 / 4-7-8 助眠 / 箱式呼吸），SVG 进度环 + 圆球缩放动画，循环与时长统计 |
| 🎧 冥想音频 | 内置 3 段冥想音频，互斥播放 + 播放状态指示 |
| 🎮 解压游戏 | 戳泡泡（Canvas 粒子 + 连击计分）与情绪记忆翻牌（3D 翻转），最高纪录本地保存 |
| 📔 心情树洞 | 心情标签（5 级 emoji）、编辑 / 删除 / 搜索、近 14 天情绪趋势图，时间线按心情着色 |
| 🖼 自绘插画 | 全站插画均为内联 SVG（数据图表 / 自然风景 / 空状态树洞），零外部素材依赖 |
| 🌙 深色模式 | 一键切换，跟随系统偏好，localStorage 持久化，图表配色联动 |

## 🛠 技术栈

- **后端**：Node.js + Express，本地 JSON 文件存储（原子写入、损坏自动备份）
- **前端**：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **图表**：Chart.js 4（CDN 加载失败时自动切换备用源）
- **设计**：CSS 变量双主题、玻璃拟态、渐变光斑背景、IntersectionObserver 滚动动画
- **测试**：jsdom 无头测试（不依赖浏览器即可验证图表配置、计分逻辑与交互状态）

## 📈 数据来源

首页图表与指标均取自中国科学院心理研究所「心理健康蓝皮书」系列公开报告，不使用估算或演示数据。每个数值在正文标出上标引用，页脚附完整出处：

| 编号 | 报告 | 引用数值 |
| --- | --- | --- |
| [1] | 《中国国民心理健康发展报告（2021～2022）》总报告 | 18–24 岁抑郁风险检出率 24.1%、25–34 岁 12.3%、全样本 10.6%（成年人样本 6859 份，覆盖 31 省） |
| [2] | 《2022 年大学生心理健康状况调查报告》 | 焦虑风险检出率 45.28%、抑郁风险检出率 21.48%（31 省近 8 万名 15–26 岁大学生） |
| [3] | 《2020 年大学生心理健康现状与需求》 | 60.8% 至少掌握一种情绪调节方式，即 39.2% 三种一种都没有（8446 名大学生，平均年龄 20.1 岁） |

各报告年份与样本口径不同，页面上已注明「不宜直接做纵向比较」。

## 🔌 API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/diaries` | 获取全部日记（新→旧） |
| POST | `/api/diaries` | 新增日记 `{ content, mood }` |
| PUT | `/api/diaries/:id` | 编辑日记 |
| DELETE | `/api/diaries/:id` | 删除日记 |
| GET / POST / DELETE | `/api/assessments` | 压力测评历史（查询 / 记录 / 清空） |
| GET | `/api/stats` | 日记数、测评数等概览 |
